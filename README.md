# ましろ

### Manga reader for Android

Discover and read manga, webtoons and comics on your phone.

**[Website and guide](https://frey004.github.io/mashiro/)**

</div>

## Download

Get the latest version from **[Releases](../../releases/latest)**:

- **Mashiro-arm64-v8a.apk**: for almost every current phone.
- **Mashiro-universal.apk**: works on any phone (larger download).

*Requires Android 8.0 or newer.*

## Features

- Read local content and online sources through extensions.
- Configurable reader: several reading modes, direction, zoom and more.
- Page turns that fold like paper, a double page view and a 3D book between chapters.
- Tracking with MyAnimeList, AniList, Kitsu and others, including linking the whole library to AniList at once.
- Library organised in categories.
- Light and dark themes, including an adjustable liquid glass theme.
- Scheduled library updates for new chapters.
- Downloads for offline reading.
- Library backups, also to your own Google Drive.

## Building

The APK is built automatically with GitHub Actions on every change and published to [Releases](../../releases). To build locally: `./gradlew assembleRelease`.
