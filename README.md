# ましろ

### Lector de manga para Android

Descubre y lee manga, webtoons y cómics desde tu móvil.

</div>

## Descarga

Descarga la última versión desde **[Releases](../../releases/latest)**:

- **Mashiro-arm64-v8a.apk**: para casi todos los móviles actuales.
- **Mashiro-universal.apk**: funciona en cualquier móvil (pesa más).

*Requiere Android 8.0 o superior.*

## Funciones

- Lectura de contenido local y de fuentes en línea mediante extensiones.
- Lector configurable: varios modos de lectura, dirección, zoom y más.
- Seguimiento con trackers como MyAnimeList, AniList, Kitsu y otros.
- Biblioteca organizada en categorías.
- Temas claros y oscuros.
- Actualizaciones programadas de la biblioteca para nuevos capítulos.
- Descargas para leer sin conexión.
- Copias de seguridad de la biblioteca.

## Compilación

El APK se compila automáticamente con GitHub Actions en cada cambio y se publica en
[Releases](../../releases). Para compilar en local: `./gradlew assembleRelease`.

## Aviso

Los desarrolladores de esta aplicación no tienen relación con los proveedores de contenido disponibles, y la aplicación no aloja ningún contenido.
